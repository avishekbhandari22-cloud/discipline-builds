# Discipline Builds

Discipline Builds is a YouTube channel of short animated films about discipline, ambition and consistency.
This repository holds the scripts and the small automation that renders one short film per day and
uploads it to the channel owner's own YouTube channel.

The app asks for one permission only: uploading videos to the owner's own channel (YouTube upload scope).
It is not offered to the public and has no other users.
